# TapBolt

TapBolt is a fast neon arcade game.

## Current build
- Mobile-first TapBolt UI
- Rush mode: 30-second target tapping
- Score, combo and earned coins
- Daily challenge placeholder
- Shop/profile/premium navigation shells
- Android debug APK build via GitHub Actions
- Download page points to the latest GitHub Release APK

## Monetization plan
- Free: ads + 1x earned coins
- Premium: no ads + 2x earned gameplay coins
- Optional consumable coin packs

## Development
The repository is the source of truth. GitHub Actions builds the Android APK on every push to main and publishes it as the latest GitHub Release asset.
